# Contributing to Yapapa

Thanks for your interest in contributing to Yapapa! 🪐

Yapapa is an open-source project and contributions of all kinds are welcome — from bug fixes and documentation improvements to new features and ideas.

## Getting Started

1. Fork the repository.
2. Clone your fork.
3. Install the dependencies:

```bash
pnpm install
```

4. Create a new branch:

```bash
git checkout -b feature/my-feature
```

5. Make your changes.
6. Test your changes locally.
7. Commit your changes.
8. Open a pull request.

## Pull Requests

Please keep pull requests focused and describe:

* What was changed
* Why the change was needed
* How the change was tested

For larger features or architectural changes, please open an issue first so the approach can be discussed before implementation.

## Issues

Before opening an issue, please search existing issues to avoid duplicates.

When reporting a bug, include:

* A clear description of the problem
* Steps to reproduce it
* Expected behavior
* Actual behavior
* Relevant error messages or logs
* Your environment and Yapapa version

## Code Style

Please follow the existing code style and conventions used throughout the project.

Keep changes simple, focused, and consistent with Yapapa's architecture.

## Development

Yapapa uses **pnpm** for package management.

Run the development environment with:

```bash
pnpm install
```

Then use the appropriate development commands for the package or example you are working on.

## Questions and Ideas

If you're unsure about an implementation or want to propose a larger change, feel free to open an issue for discussion.

Thanks for helping make Yapapa better! 🚀
