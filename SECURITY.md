# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Yapapa, please **do not open a public GitHub issue**. You can contact me on [my twitter](https://x.com/hxrshdeepsingh).

Instead, report the vulnerability privately through **GitHub Security Advisories**.

Please include as much information as possible, such as:

* A description of the vulnerability
* Steps to reproduce the issue
* The affected version
* The potential impact
* Any possible mitigation or fix

We will review security reports and work to address verified vulnerabilities as quickly as possible.

## Supported Versions

Yapapa is currently under active development, so security support may vary between releases.

For the latest security fixes, please use the most recent version of Yapapa.
